🔑 Google OAuth Client ID (eenmalig)

Omdat deze app direct op jouw telefoon draait zonder tussenserver, gebruikt hij jouw eigen Google Client ID voor veilige toegang tot Gmail (alleen lezen) en Google Drive:

  1. Open console.cloud.google.com → maak een project en zet Gmail API & Google Drive API aan.
  2. Ga naar Credentials → Create Credentials → OAuth client ID (Web application).
  3. Voeg deze pagina-URL toe bij Authorized JavaScript origins en plak hieronder het Client ID.

📲 App op Mobiel & Reisgenoten Koppelen

Lokaal & Offline Gereed
Zo zetten jullie de app op alle 3 de telefoons:
  1. Deel jullie GitHub-link: Tik hieronder op "📋 Deel Link & Code" en stuur het bericht via WhatsApp naar je reisgenoten.
  2. Installeer op startscherm: • Android (Chrome): Tik op ⋮ → "App installeren" / "Toevoegen aan startscherm". • iPhone (Safari): Tik op Deel-icoon (□↑) → "Zet op beginscherm".
  3. Wijzigingen delen: Tik onderaan op “📤 Deel met reisgenoten” en stuur het bestand (WhatsApp, AirDrop). De ander tikt op “📥 Ontvangen bestand samenvoegen”. Uitgaven, vinkjes en aangepaste dagen van beide telefoons blijven bewaard; per onderdeel telt de laatste wijziging.
